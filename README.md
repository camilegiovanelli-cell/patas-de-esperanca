# Patas de Esperança

Projeto acadêmico de desenvolvimento web para uma ONG fictícia voltada à castração e proteção de gatos comunitários.

## Estrutura
- index.html — apresentação da ONG
- projetos.html — projetos, doações e voluntariado
- cadastro.html — formulário de engajamento
- style.css — estilos
- assets/ — imagens utilizadas no projeto

## Observação
O formulário usa validações nativas HTML5 e JavaScript para as máscaras de CPF, telefone e CEP.


## Etapa 2 — Feedback e microinterações
O projeto inclui badges, caixa de alerta, modal com `<dialog>` e toast de confirmação no formulário, mantendo a identidade visual e os recursos de acessibilidade.
